## Назначение проекта

Проект представляет собой TypeScript-библиотеку для работы с OAuth-аутентификацией через различные провайдеры (Google, VK, Яндекс, Mail.ru, Keycloak, Telegram и др.).  
Библиотека предназначена для интеграции OAuth-авторизации в веб- и гибридные приложения с поддержкой всплывающих окон (pop-up) и мобильных плагинов (Cordova).

---

## Архитектура и основные компоненты

### 1. **Базовые абстракции**
- **OAuthBase** — абстрактный класс, реализующий общую логику для OAuth-провайдеров: открытие pop-up, обработка редиректов, получение токена/кода, парсинг ошибок, хранение состояния.
- **OAuthUser** — абстрактный класс пользователя, описывающий общие поля (id, name, email, avatar и др.) и методы для парсинга данных пользователя.
- **PopUpBase** — базовый класс для работы с pop-up окнами: открытие, отслеживание закрытия, обработка сообщений между окнами, управление параметрами.

### 2. **Провайдеры OAuth**
Для каждого провайдера реализованы свои классы:
- **Google**: `GoAuth`, `GoUser`
- **VK**: `VkAuth`, `VkUser`
- **Яндекс**: `YaAuth`, `YaUser`
- **Mail.ru**: `MaAuth`, `MaUser`
- **Keycloak**: `KeycloakAuth`, `KeycloakUser`
- **Telegram**: `TgAuth`, `TgUser`, `TgApiLoader`

Каждый класс-наследник реализует:
- Формирование URL для авторизации
- Получение профиля пользователя по токену
- Получение токена по коду авторизации
- Парсинг специфичных для провайдера данных

### 3. **Внешние интеграции**
- **external/** — содержит интеграции с браузерными pop-up и Cordova-плагинами (`browser.ts`, `cordovaOAuthPlugin.ts`, `cordovaInAppBrowserPlugin.ts`).  
  Это позволяет использовать библиотеку как в обычных браузерах, так и в мобильных приложениях на Cordova.

### 4. **Утилиты и вспомогательные классы**
- **OAuthParser** — парсит параметры и ошибки из URL/фрагментов, возвращает стандартизированные объекты.
- **public-api.ts** — единая точка экспорта всех публичных классов и функций библиотеки.

## Принципы работы

1. **Инициализация**  
   Для каждого провайдера создаётся свой экземпляр класса (например, `new GoAuth(...)`), куда передаются параметры приложения и окно.

2. **Аутентификация**  
   - Открывается pop-up окно с URL авторизации.
   - Пользователь проходит OAuth-авторизацию.
   - После редиректа pop-up отправляет сообщение в основное окно.
   - Сообщение парсится, извлекается код или токен.

3. **Получение профиля**  
   - По полученному токену запрашивается профиль пользователя через API провайдера.
   - Данные парсятся в объект-наследник `OAuthUser`.

4. **Унификация интерфейса**  
   Все провайдеры реализуют одинаковые методы (`getProfile`, `getTokenByCode`, `getCode`, `getToken`), что позволяет использовать их взаимозаменяемо.

## Преимущества и особенности

- **Модульность**: легко добавить нового провайдера, реализовав пару классов.
- **Расширяемость**: поддержка разных платформ (браузер, Cordova).
- **Типизация**: строгий TypeScript, интерфейсы, дженерики.
- **Унификация**: единый интерфейс для всех OAuth-провайдеров.
- **Гибкость**: можно использовать как в SPA, так и в гибридных мобильных приложениях.

## Для кого и для чего

- **Для разработчиков**, которым нужно быстро и безопасно интегрировать OAuth-авторизацию через популярных провайдеров в свои приложения.
- **Для проектов**, где требуется поддержка нескольких платформ (веб, мобильные приложения на Cordova).
